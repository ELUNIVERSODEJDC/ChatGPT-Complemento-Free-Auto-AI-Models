AUTO FREE PARA CODEX JDC — 0.2.0

Integra la ruta real kilo-auto/free del servicio Kilo en el selector de Codex.
Kilo elige el modelo gratuito disponible; no se copia ni se instala Kilo Code.
Ya no se ofrecen MiniMax, DeepSeek y GLM mediante NVIDIA.

INSTALAR
1. Requiere Windows y Node.js 22 o posterior.
2. Ejecuta INSTALAR.cmd. Registra el complemento en el mercado personal,
   comprueba una respuesta real de Kilo y activa el proveedor local.
3. Tras una instalación correcta, el instalador reinicia Codex.
4. En Plugins aparece Auto Free para Codex JDC. Actívalo para el arranque
   automático del puente. En el selector elige Kilo Auto Free.
No necesitas clave API ni tarjeta para la ruta anónima gratuita.
Los modelos GPT del catálogo de OpenAI se conservan.

ACTUALIZAR DESDE MINIMAX JDC
La identidad técnica minimax-jdc, el puerto local y la carpeta de datos se
mantienen para actualizar el mismo complemento. La antigua clave cifrada no
se descifra, no se envía a Kilo y no se borra. La ventana de clave se retira.
Los chats antiguos con modelos NVIDIA ya no tienen una ruta activa en esta
versión: cambia su modelo a Kilo Auto Free o abre un chat nuevo.

USO Y LÍMITES
El catálogo de Kilo consultado el 29/10/2026 anuncia 256000 tokens de contexto,
32768 de salida máxima, texto y herramientas. No anuncia imágenes para Auto
Free. Se conserva el historial completo, las llamadas y los resultados de
herramientas; la compatibilidad nativa de cada función debe comprobarse.
Kilo elige el razonamiento del modelo; no se anuncia un control de esfuerzo
que esta ruta no garantiza. El modelo real puede cambiar entre peticiones.
Los modelos gratuitos, su disponibilidad y sus límites pueden variar.
Kilo documenta 200 peticiones por hora e IP para acceso anónimo. No hay
fallback de pago. Un 429 se informa como límite de Kilo, no como éxito.
Los proveedores pueden registrar consultas y utilizarlas para mejorar sus
servicios. No uses esta ruta gratuita con datos personales o confidenciales.

GESTIÓN
MCP: estado_auto_free, configurar_auto_free y restaurar_proveedor.
Las llamadas históricas estado_minimax/configurar_minimax siguen siendo
alias de gestión; ya no configuran NVIDIA ni abren su ventana de clave.
RESTAURAR PROVEEDOR.cmd vuelve al proveedor anterior sin restaurar una copia
antigua de toda la configuración. Restaura antes de desinstalar.
La configuración directa y MCP conservan Codex abierto. El instalador externo
reinicia sólo después de verificar conexión y configuración.
